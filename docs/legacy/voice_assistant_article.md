```python
class VoiceAssistant:
    def _toggle_recording(self, _):
        """空格键监听：一按开始，再按结束"""
        if self.processing:
            print("别急！AI还在思考人生...")
            
    def _text_to_speech(self, text):
        """让AI开口说话的正确姿势"""
        # 每次新建引擎避免"卡痰"
        engine = pyttsx3.init()
        engine.say(text)
        engine.runAndWait()
```

**踩坑警示**：`pyttsx3`的引擎不能重复使用，否则会像复读机一样卡壳！

## 五、常见翻车现场与自救指南

### 1. 错误：run loop already started
**症状**：第二次语音播报卡壳  
**解药**：每次新建pyttsx3引擎（就像用一次性筷子一样）

### 2. 错误：录音没反应
**自查清单**：
- 麦克风权限给了吗？
- Vosk模型路径对了吗？
- 是不是在图书馆偷偷运行？（静音模式要关闭）

### 3. AI突然变哑巴
**诊断步骤**：
```python
print(response.status_code)  # 看看是不是把服务器聊崩了
检查Flask服务是否健在
```
